\# Minecraft AI Companion



A local-first AI companion for Minecraft that can chat with players, understand natural-language instructions, and perform actions inside the game.



The project is designed to run locally without requiring a paid LLM API.



\## Current Features



\- Local LLM through Ollama

\- Natural conversation inside Minecraft

\- Natural-language action selection

\- Follow the player

\- Come to the player

\- Stop and wait

\- Mineflayer pathfinding

\- Conversation history

\- No paid LLM API required



\## Current Stack



\- Minecraft Java Edition 1.21.11

\- Node.js

\- Mineflayer

\- mineflayer-pathfinder

\- Ollama

\- Qwen3-VL 8B

\## Goal



The long-term goal is to create an AI companion that feels like another player rather than a command-based Minecraft bot.



The companion should eventually be able to see the world, talk naturally, remember previous experiences, react to danger in real time, explore, fight, gather resources, build, and play alongside the player.
